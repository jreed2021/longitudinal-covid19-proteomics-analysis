# Original research data

This project analyzes publicly released data from Gisby et al. (2021), *Longitudinal proteomic profiling of dialysis patients with COVID-19 reveals markers of severity and predictors of death*, eLife, https://doi.org/10.7554/eLife.64827.

Obtain these original files from the authors’ repository: https://github.com/jackgisby/longitudinal_olink_proteomics/tree/main/data

- `plasma_npx_level.csv`
- `plasma_sample_level.csv`

Place the two CSVs in this directory before executing the pipeline. They are not included in this distribution to keep derived code and source data separate. The original repository describes its materials as CC BY 4.0; retain attribution and consult the original license before redistribution. Do not commit private or newly collected patient data.
